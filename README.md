十三页作品集，包含：

- 老公菜谱：AI 菜谱整理、前后端实现与部署实践。

## 展示范围

AccessPilot 使用虚构业务数据、模拟登录与模拟 IAM；测试数据注明历史验收版本。AccessPilot 展示申请确认、人工审批、模拟开通与授权回读。老公菜谱使用本地 Mock 解析及人工修订的演示数据，展示导入、确认、详情与复盘；不代表真实模型解析效果，线上入口需授权访问。宝宝今夜谈在本作品集中展示原型范围，不代表对应后端服务已完成。
